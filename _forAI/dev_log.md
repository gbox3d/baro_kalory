### 2026-08-04 (2차) — 이전 완료 · 최초 커밋

- **UI 전량이 옮겨 왔다.** 페이지 7 · 브라우저 모듈 11 · 테스트 7파일. 워크스페이스 밖에서
  독립 패키지로 성립하는 것까지 확인했다(`pnpm install` → `pnpm build` → `pnpm test` 59/59).
- **유출 감사 통과.** 사설 IP·실기 호스트명·계정명·형제 호스트 참조 0건. 「비밀번호」로
  걸리는 것은 전부 입력 필드와 i18n 문자열이지 값이 아니다. `git init` 을 새로 했으므로
  원본의 옛 이력(과거 실접속정보가 있던 시기)은 따라오지 않는다.
- **원본에서 제거됐다.** 형제 저장소의 `apps/frontend` 삭제 완료. 그쪽에는 이제 정적
  산출물도 빌드 단계도 없다.
- **마운트 프리픽스를 앱에서 걷어냈다.** 이 앱은 자기 오리진의 **루트**에 선다.
  `/barocalory` 는 예전에 프록시가 붙인 네임스페이스였을 뿐인데 앱의 사실인 양 코드에
  눌어붙어 있었다. 이 프로젝트는 리버스 프록시를 폐기했으므로(이교수님 확정) API 는 언제나
  교차 출처이고, 백엔드의 CORS 옵트인이 배포의 전제가 된다.
- **API 주소에 기본값을 두지 않기로 했다.** 분리 배포에서 "같은 곳에 있겠거니"는 틀린 쪽이
  정상이라, 미설정 상태를 그대로 드러낸다(배너 + 설정·대문 외 잠금). 설정 화면에 연결 테스트
  버튼을 붙여 주소를 넣고 바로 확인할 수 있게 했다.
- **프리뷰 관련 결함 셋을 고쳤다.**
  - **유령 fetch 경합**: `start()` 가 이전 `stop()` 을 await 하는 사이 새 요청이 끼어들어
    두 스트림이 겹쳤다. 세대 토큰(`gen`)으로 늦게 도착한 시작을 버린다.
  - **폴백 고착**: 스트림이 501 이면 스냅샷으로 내려앉는데, 그 상태가 **기기를 바꿔도** 안
    풀려 실기로 전환해도 계속 저fps 였다. 기기 전환 시 폴백 상태를 초기화한다.
  - **정지 화면의 깨진 이미지**: `src` 없는 `<img>` 를 브라우저가 깨진 링크 아이콘으로
    그렸다. 그리고 **대기(접속 시도 중)와 정지(안 켠 상태)를 뭉쳐 놓아서**, 프리뷰가 기본
    꺼짐인 페이지가 아무것도 기다리지 않으면서 `Wait...` 를 영원히 띄웠다. 두 상태를 갈라
    첫 페인트부터 「정지됨」을 중앙에 쓴다.
- **남은 것**: 정적 배포처 확정(혼합 콘텐츠가 실제 판단 기준) · 원격 저장소 연결.
