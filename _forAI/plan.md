## Near-term work

### 0. 중복 실측 결과 — 여기서 시작한다 (2026-08-19 조사, 관심사 5/6 완료)

관심사별로 6개 조사를 병렬로 돌려 5개가 끝났다(`panels` 미완 — 패널·모달·확인창·메시지줄).
**중복 약 700줄**이 나왔고, 더 중요한 것은 그중 상당수가 **갈라져 있다(drifted)** 는 것 —
같은 목적인데 동작이 달라 이미 버그다. 리팩토링의 근거가 "정리"가 아니라 **정합성**이다.

**드리프트 = 지금 살아 있는 버그. 이 순서로 잡는다.**

1. **`num()` 계열이 `null` 을 `0` 으로 만든다.** `Number(null) === 0` 이고 유한하다 —
   `finiteNum(null)` 이 `null` 이 아니라 **0** 을 돌려준다(오늘 실측 확인). 「값 없음」이
   「0」으로 렌더된다. 5개 페이지에 제각기 구현돼 있고, `undefined` 는 맞게 처리하므로
   증상이 산발적이다. `settleMs: null` 인 표본이 「0.0s」로 뜬다.
2. **같은 「게이트 떨어짐」이 화면마다 다른 색이다.** calibration 은 실패 셀을
   `--color-danger`(빨강), height 은 실패 행을 `--color-warn`(호박). 같은 사실, 두 색.
3. **`fmtDur` 이 음수 구간을 반대로 처리한다.** 브라우저 시계가 서버보다 뒤지면 도달하는
   경로다(calibration ↔ height).
4. **404 정책이 4개 페이지에서 다르다.** 같은 `GET /profiles/camera/:id` 인데 「미발행」을
   각자 다르게 해석한다.
5. **`fixed()` 가 숫자 문자열을 「—」로 만든다.** calibration 판이 `Number()` 를 안 불러서
   JSON 에서 온 `"12.5"` 가 값 없음으로 렌더된다.
6. **설치 높이 발행이 두 벌이고 동작이 4가지 다르다**(settings 34줄 · height 34줄).
7. **`setBusy` 가 4개 판**이고, 전부 `querySelectorAll("button")` 로 싹 잠근다 — 그 부작용을
   피하려고 이미 **우회 3개**가 생겼다(height 의 `BUSY_EXEMPT`, simulator 의 감추기,
   calibration 의 손수 개별 잠금).

**추출 대상 — 절감 큰 순서** (각 페이지 인라인에서 빠지는 줄 수 합계)

| 모듈 | 무엇 | 페이지 | 대략 |
|---|---|---|---|
| `src/form.mjs` | 필드↔객체 바인딩 · 숫자 읽기 · 비밀필드 규약 · `<select>` 채우기 · 상태줄 | settings · simulator · calibration · height | **~240줄** |
| `src/errors.mjs` + `src/prefs.mjs` | 거절 본문 읽기(`hint`·`code`·`failures`) · 404=답 · 501=미지원 · `실패: {e.message}` 65곳 · localStorage try/catch 22곳 | 6개 페이지 전부 | **~155줄** |

**작업 순서 — 이 순서인 이유가 있다**

1. **`format.mjs` 먼저.** 다른 모듈들이 전부 이걸 쓴다(`fixed` 는 `num` 위에, `fmtWhen`·
   `fmtDur` 는 `pad2` 위에). 그리고 드리프트 1·3·5 를 여기서 한 번에 없앤다. 순수 함수라
   **단위 테스트가 붙는다** — 지금 없는 종류의 그물이다.
2. **`errors.mjs` + `prefs.mjs`.** 호출 지점이 제일 많아(≈90곳) 값이 크고, 순수하게
   기계적이라 위험이 낮다. `api.mjs` 가 이미 `err.status`·`err.body` 를 실어 주므로 읽는
   쪽만 한 곳으로 모으면 된다.
3. **`job-poll.mjs` + `busy-lock.mjs`.** 여기서 실제 동작이 바뀐다(폴링 네 축을 하나로
   맞추는 일). **브라우저로 왕복 확인이 필수** — 정규식 테스트가 못 잡는 영역이다.
   `busy-lock` 은 우회 3개를 걷어내는 게 목적이므로, `exempt` 를 계약으로 받는다.
4. **`form.mjs`.** 절감이 가장 크지만 화면 상태를 만지므로 셋 다음에 온다. 설치 높이
   발행(드리프트 6)을 한 벌로 합치는 것이 이 단계의 본론.
5. **`table.mjs`.** 마지막. 값은 작지만 드리프트 2(색 불일치)를 고치고, `app.css` 에 공용
   `table` 규칙이 **아예 없다**는 것도 여기서 정리한다(그래서 두 페이지가 각자 재발명했다).

**주의:** 위 모듈들은 `src/` **평면**에 둔다 — `pack.mjs` 가 하위 폴더를 안 옮기므로(§3)
`src/pages/…` 로 내려가는 것은 그 걸림돌을 고친 뒤다. 페이지 로직 추출(§1·§2)과 **이
중복 제거는 독립이다** — 뷰 계층 결정을 기다리지 않고 오늘 순서대로 진행할 수 있다.

**미완:** `panels` 관심사(패널·모달·확인창·메시지줄) 조사와 종합 단계가 안 끝났다.
`Workflow({scriptPath: "…/kalory-duplication-sweep-wf_a2c70f34-058.js", resumeFromRunId:
"wf_a2c70f34-058"})` 로 이어서 돌리면 끝난 5개는 캐시에서 즉시 돌아온다.


### 1. 뷰 계층 결정 — 내일 첫 일감 (설계 논의, 코드 아님)

세 갈래다. 값과 비용을 같이 적는다.

- **A. 추출만 한다(뷰 계층 없음).** 페이지 로직을 `src/pages/<페이지>/*.mjs` 로 옮긴다.
  값: 파일이 작아지고 테스트·재사용이 쉬워진다. 빌드 단계 0, 의존성 0 유지.
  **한계: 기능당 비용이 그대로다.** 다음 기능도 createElement 를 손으로 짠다.
- **B. 번들러 + 프레임워크(React 등).** 값: 선언적 렌더로 기능당 비용이 실제로 떨어지고
  컴포넌트 재사용이 생긴다. 비용: 빌드 파이프라인, `dist/` 가 번들이 되어 **오늘 같은
  "브라우저에서 셋 코드 그대로 검증"이 어려워진다**, 의존성 트리가 생긴다.
- **C. 무번들 뷰 계층(권고).** 선언적 템플릿 라이브러리를 **ESM 로 벤더링**해
  (`src/vendor/`) 지금의 `./web/` 적재 그대로 쓴다. 값: B 의 기능당 비용 절감을 얻고
  정적 호스트·무번들·CDN 무의존을 유지한다. 비용: 벤더 파일이 저장소에 들어오므로
  「런타임 의존성 0개」가 깨진다(3rd-party 코드가 커밋된다). 갱신은 손으로 한다.

**결정 기준은 하나로 두자 — "다음 기능 하나를 넣는 비용이 줄어드는가."** 그 기준에서 A 는
탈락이고, B 와 C 의 차이는 빌드 단계를 받아들일지다.

### 3. 파일럿 전에 치워야 하는 걸림돌 셋 (실측 확인됨)

- **`pack.mjs` 의 `src` 복사가 평면이다** — `readdirSync(src)` + `.mjs` 필터라 **하위 폴더를
  안 옮긴다.** `src/pages/…` 로 추출하면 `dist/web/pages/…` 가 비어 배포가 조용히 깨진다.
  재귀 복사로 바꾸고 테스트로 잡는다. (`server.mjs` 의 `/web/` 서빙은 하위 경로를 이미 넘긴다.)
- **`styles/tailwind.css` 의 `@source` 는 글로브가 아니라 파일 나열이다.** 클래스 문자열이
  `.mjs` 로 옮겨 가면 `@source "../src/*.mjs"` 가 하위 폴더를 못 본다 — 빠뜨리면 그 화면만
  스타일이 사라진다.
- **테스트 11곳이 `public/*.html` 소스를 읽어 단언한다**(`settings-calibration-pages.test.mjs`).
  추출하면 그 단언들의 대상이 모듈로 바뀐다. **이건 마찰이지 손해가 아니다** — 다만 같은
  커밋에서 함께 옮겨야 하고, 옮기는 동안 회귀 그물이 얇아지는 구간이 생긴다.

## Structure decisions

- **이름은 `baro_kalory` 로 확정.** 형제 저장소 `baro_calrory` 와의 `c`/`k` 차이는 오타가
  아니라 **의도된 말장난**이다(2026-08-04 확인) — **백엔드는 `c`alrory, 프런트는
  `k`alory**. 즉 철자 한 글자가 저장소 구분자다. 다만 `grep` 이 한쪽만 잡는다는 함정이
  있으니, 두 저장소를 함께 훑을 때는 패턴을 `[ck]al` 로 쓴다.
- **광학 모델을 이 저장소에 두지 않는다.** 화각·투영·조준은 백엔드가 계산해 값으로 내려준다.
  두 벌로 갈라지면 조용히 틀린 화면을 그린다.
- **무번들 바닐라를 유지한다.** 빌드는 Tailwind 하나. 번들러를 들이면 정적 배포가 단순해지는
  것이 아니라 복잡해진다.
- **백엔드 주소를 저장소에 박지 않는다.** 사용자가 런타임에 지정한다(`memo.md` 「API 주소
  주입」). 개발용 `server.mjs` 의 값도 gitignore 된 `.env` 가 유일한 출처다.
- **백엔드 주소의 기본값을 만들지 않는다(2026-08-04).** 분리 배포에서 "같은 곳에 있겠거니"는
  **틀린 쪽이 정상**이라, 추측하는 대신 미설정 상태를 그대로 드러낸다 — 배너로 알리고 설정·
  대문을 뺀 바로가기를 잠근다. 설정 화면에는 주소를 넣고 바로 확인할 연결 테스트를 둔다.
- **리버스 프록시를 전제하지 않는다(2026-08-04 확정, 이교수님).** 서비스는 각자 자기 포트로
  서고, `barocalory`·`kalory` 는 **프로젝트 이름일 뿐 URL 경로가 아니다.** 따라서 API 는
  언제나 교차 출처이고, 백엔드의 CORS 옵트인이 배포의 전제 조건이다. 다만 **정적 배포에서는
  저장소 이름이 base path 가 된다** — 그래서 링크는 전부 상대경로이고 `pack.mjs` 가 정적
  표식과 디렉터리 URL 재작성을 한다. 루트 절대경로를 쓰면 첫 화면이 잠긴다(실제로 그랬다).
- **버전 정합 테스트는 리터럴을 박지 않는다.** 앱마다 자기 semver 를 드는지만 본다 —
  저장소 간 버전 비교는 하지 않는다(각자 독립 배포다).
- **판정을 화면이 다시 계산하지 않는다.** 드리프트·검증 판정·게인 계산은 백엔드가 하고 화면은
  그 답을 옮긴다. 두 번째 구현이 생기면 두 구현은 언젠가 서로 다른 답을 낸다.

## 열린 결정

아직 정하지 않았고, 정해야 진행되는 것들이다.

- **없음.** 「`_forAI/` 공개 여부」는 두되 내부 사실을 적지 않는 방식으로 확정됐다(규칙은
  `README.md` 「공개 저장소 규칙」이 갖는다). 「버전 정합 테스트의 거처」도 위 구조 결정으로
  답이 났다. 새로 열리는 결정은 여기 적는다.

## Risks

- **발행본에 백업이 없다.** 프로파일은 git 밖 `localfiles/profiles/camera/` 에 있고 백업도
  복원 라우트도 **의도적으로** 없다(보드 #76 — 리그가 바뀐 곡선을 되살리는 기계가 #61 의
  재발이라서). 20분 스윕 결과를 잃으면 재측정뿐이다. **화면이 복원·백업을 약속하지 않게**
  지키는 것이 우리 몫이다.
- **혼합 콘텐츠.** https 정적 호스팅에서 http 백엔드는 브라우저가 차단한다. 배포를 가르는
  선결 조건은 아니게 됐다 — UI 가 부르기 전에 판정해 알린다(`src/api.mjs`
  `mixedContentBlocked`). 남은 리스크는 https 백엔드(또는 터널) 확보다.
- **CORS 는 이 저장소가 고칠 수 없다.** 백엔드가 배포 오리진을 허용해야 한다.
- **미러 드리프트.** 페이지 목록은 `src/pages.mjs` 가 정본이고 `server.mjs` 의
  `PAGE_ROUTES`·`PAGE_REDIRECTS` 와 `styles/tailwind.css` 의 `@source` 는 손으로 맞추는
  미러다. 한쪽만 고치면 404 가 난다.
- **계약이 하루에 여러 번 바뀔 수 있다.** 2026-08-19 에 백엔드가 0.17.0→0.19.0 을 하루에
  올렸고, 같은 필드의 의미가 이틀 새 세 번 바뀐 적도 있다(`restartRequired`). 그래서 화면은
  응답을 읽고, **시점·상태를 예측해 문구에 박지 않는다** — 박으면 다음 변경에 조용한
  거짓말이 된다.
- **공개 이력은 되돌릴 수 없다.** 커밋 전에 유출 감사를 끝낸다. 사설 IP·실기 호스트명·계정명·
  토큰은 주석·placeholder·테스트 픽스처·문서 전부에서 뺀다.
