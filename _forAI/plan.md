#### 착수 전에 반드시 지킬 다섯 (1단계에서 실측으로 배운 것)

1. **조사 결과를 그대로 근거로 쓰지 않는다 — 착수 전에 반증한다.** 위 조사의 드리프트 목록 중
   **셋이 틀렸다**(존재하지 않는 함수를 주어로 쓴 것, 페이지 수가 실제의 절반인 것, 축을 잘못
   잡은 것). 그대로 손댔으면 세 번 다 엉뚱한 데를 고쳤을 것이다.
2. **어떤 공용 모듈도 단위를 붙이면 안 된다.** `°`·`m`·`px`·`%` 가 i18n 사전 키 문자열 **안에**
   박혀 있다(`t("설치 하향각 {d}°")`). 단위까지 붙이면 `"12.3°°"` 가 되고, 사전 키를 고치면
   **i18n 이 원문을 키로 쓰므로** 그 항목의 번역이 통째로 끊긴다.
3. **공용 함수는 `null` 을 돌려주면 안 된다.** `t()` 는 `params[k] != null` 일 때만 치환하므로,
   `null` 을 넘기면 화면에 리터럴 `{d}` 가 남는다.
4. **「값 없음」 표기는 상수가 아니라 인자다.** `—`(표의 빈 칸 = 해당 없음)와 `?`(값을 못 읽음)는
   **의도된 구분**이고, `<input type="number">` 의 value 에는 `""` 여야 한다. 하나로 강제하면
   세 뜻이 뭉개진다. simulator 는 `level !== "—"` 로 **sentinel 되읽기**까지 한다(줄번호는 밀리니 내용으로 grep).
5. **clamp·퍼센트·SVG 좌표는 포맷이 아니다.** 옮긴다면 geom 모듈이고, **짝을 흩으면 안 된다** —
   cctv 의 clamp 은 「그리는 쪽과 세는 쪽이 같은 값을 봐야 한다」는 짝이 있다(흩자 화면은
   비었는데 "박스 n개"가 되는 결함이 실제로 났다). height 의 `1~30 m` 는 clamp 처럼 생겼지만
   **거절**이다 — 자르면 cm 오입력이 30 m 로 발행된다.

### 3. 파일럿 관련 걸림돌 셋 (실측 확인됨 · React 확정으로 거취 재평가)

> React 확정으로 셋 다 성격이 바뀌었다 — 「고칠 것」이 아니라 대부분 「Vite 가 없앨 것」이다.
> `pack.mjs` 평면 복사는 **고치지 않는다**(퇴역 후보를 수리하지 않는다 — 그때까지 `src/`
> 평면 유지). `@source` 는 `@tailwindcss/vite` 가 대체한다(그때까지 새 `.mjs` 는 손으로
> 추가). 테스트 11곳의 HTML 정규식 단언만 여전히 실물이다 — calibration 을 컴포넌트로 옮길
> 때 그 단언들을 같은 강도로 함께 옮긴다(약화 금지).

- **`pack.mjs` 의 `src` 복사가 평면이다** — `readdirSync(src)` + `.mjs` 필터라 **하위 폴더를
  안 옮긴다.** `src/pages/…` 로 추출하면 `dist/web/pages/…` 가 비어 배포가 조용히 깨진다.
  재귀 복사로 바꾸고 테스트로 잡는다. (`server.mjs` 의 `/web/` 서빙은 하위 경로를 이미 넘긴다.)
- **`styles/tailwind.css` 의 `@source` 는 글로브가 아니라 파일 나열이다.** 클래스 문자열이
  `.mjs` 로 옮겨 가면 `@source "../src/*.mjs"` 가 하위 폴더를 못 본다 — 빠뜨리면 그 화면만
  스타일이 사라진다.
- **테스트 11곳이 `public/*.html` 소스를 읽어 단언한다**(`settings-calibration-pages.test.mjs`).
  추출하면 그 단언들의 대상이 모듈로 바뀐다. **이건 마찰이지 손해가 아니다** — 다만 같은
  커밋에서 함께 옮겨야 하고, 옮기는 동안 회귀 그물이 얇아지는 구간이 생긴다.

### 4. `i18n.mjs` 는 별건으로 따로 본다

1,113줄 · 항목 686개인데 **다국어는 동결 상태다**(한글만, 이교수님 지시). 지금 이 파일이 만드는
값은 사실상 0 이고, 새 문자열마다 손이 간다. 구조(`t()` 래퍼·언어 셀렉터)는 유지하라는 지시가
있으므로 **파일을 없애는 게 아니라 사전 항목을 어떻게 둘지**를 정하는 문제다. 뷰 계층 결정과
섞지 않는다.

### 6. 옛 계약 폴백 넷 걷어내기 (위 5 의 답이 나온 뒤)

`public/calibration.html` 에 **의도적으로** 남긴 것들이다. 지울 때 함께 지울 것을 적어 둔다 —
나중에 코드만 보면 의도된 폴백과 잔재를 구분할 수 없다.

- `reload` 블록 없는 응답 → `POST /cctv/active {force:true}` 재선택
  (`applyPublishedToRuntime`). 지우면 `appliedSuffix` 의 `reselect`·`failed` 갈래도 죽는다.
- `optics.source` 없는 추론 → 발행본 존재 재조회(`/revisions` 404 판정)·`declared` 추론

각 갈래를 지울 때 대응 테스트 단언도 함께 지운다.

### 7. 실기 잔여

- **z16384 는 실측이 아니라 보간이다** — 야간·저조도로 정합 실패했다. **지금 곡선 그대로 써도
  된다**(물리적으로 단조하고 조준이 깨지지 않는다). 최대 배율에서 화면 구석 정확도만 실측
  구간보다 낮다. 불편이 실제로 느껴질 때 밝은 낮에 한 번 더 돌리면 보간이 실측으로 바뀐다.

  물리적으로 2곳이 된 실측이 보드 #99 다. Hucoms 계열은 폴백이 곧 자기 눈금이라 안전하다.
  설정 화면의 씨앗값 경고가 이 사고의 예방 문구다.

## Structure decisions

- **이름은 `baro_kalory` 로 확정.** 형제 저장소 `baro_calrory` 와의 `c`/`k` 차이는 오타가
  아니라 **의도된 말장난**이다(2026-08-04 확인) — **백엔드는 `c`alrory, 프런트는
  `k`alory**. 즉 철자 한 글자가 저장소 구분자다. 다만 `grep` 이 한쪽만 잡는다는 함정이
  있으니, 두 저장소를 함께 훑을 때는 패턴을 `[ck]al` 로 쓴다.
- **광학 모델을 이 저장소에 두지 않는다.** 화각·투영·조준은 백엔드가 계산해 값으로 내려준다.
  두 벌로 갈라지면 조용히 틀린 화면을 그린다.
- ~~무번들 바닐라를 유지한다~~ → **뒤집힘(2026-08-22, 이교수님): React + Vite 로 간다.**
  원 결정은 앱이 작을 때의 것이고, 「기능 산더미 + 코드 건강 악화」가 전제를 바꿨다.
  결정 기준은 §1 에 — 기능당 비용이 우선이고, Vite 가 자작 도구(server.mjs·pack.mjs)를
  흡수해 배포는 오히려 단순해진다.
- **백엔드 주소를 저장소에 박지 않는다.** 사용자가 런타임에 지정한다(`memo.md` 「API 주소
  주입」). 개발용 `server.mjs` 의 값도 gitignore 된 `.env` 가 유일한 출처다.
- **백엔드 주소의 기본값을 만들지 않는다(2026-08-04).** 분리 배포에서 "같은 곳에 있겠거니"는
  **틀린 쪽이 정상**이라, 추측하는 대신 미설정 상태를 그대로 드러낸다 — 배너로 알리고 설정·
  대문을 뺀 바로가기를 잠근다. 설정 화면에는 주소를 넣고 바로 확인할 연결 테스트를 둔다.
- **리버스 프록시를 전제하지 않는다(2026-08-04 확정, 이교수님).** 서비스는 각자 자기 포트로
  서고, `barocalory`·`kalory` 는 **프로젝트 이름일 뿐 URL 경로가 아니다.** 따라서 API 는
  언제나 교차 출처이고, 백엔드의 CORS 옵트인이 배포의 전제 조건이다. 다만 **정적 배포에서는
  저장소 이름이 base path 가 된다** — 그래서 링크는 전부 상대경로이고 `pack.mjs` 가 정적
  표식과 디렉터리 URL 재작성을 한다. 루트 절대경로를 쓰면 첫 화면이 잠긴다(실제로 그랬다).
- **버전 정합 테스트는 리터럴을 박지 않는다.** 앱마다 자기 semver 를 드는지만 본다 —
  저장소 간 버전 비교는 하지 않는다(각자 독립 배포다).
- **판정을 화면이 다시 계산하지 않는다.** 드리프트·검증 판정·게인 계산은 백엔드가 하고 화면은
  그 답을 옮긴다. 두 번째 구현이 생기면 두 구현은 언젠가 서로 다른 답을 낸다.

## Risks

- **발행본에 백업이 없다.** 프로파일은 git 밖 `localfiles/profiles/camera/` 에 있고 백업도
  복원 라우트도 **의도적으로** 없다(보드 #76 — 리그가 바뀐 곡선을 되살리는 기계가 #61 의
  재발이라서). 20분 스윕 결과를 잃으면 재측정뿐이다. **화면이 복원·백업을 약속하지 않게**
  지키는 것이 우리 몫이다.
- **혼합 콘텐츠.** https 정적 호스팅에서 http 백엔드는 브라우저가 차단한다. 배포를 가르는
  선결 조건은 아니게 됐다 — UI 가 부르기 전에 판정해 알린다(`src/api.mjs`
  `mixedContentBlocked`). 남은 리스크는 https 백엔드(또는 터널) 확보다.
- **CORS 는 이 저장소가 고칠 수 없다.** 백엔드가 배포 오리진을 허용해야 한다.
- **미러 드리프트.** 페이지 목록은 `src/pages.mjs` 가 정본이고 `server.mjs` 의
  `PAGE_ROUTES`·`PAGE_REDIRECTS` 와 `styles/tailwind.css` 의 `@source` 는 손으로 맞추는
  미러다. 한쪽만 고치면 404 가 난다.
- **계약이 하루에 여러 번 바뀔 수 있다.** 2026-08-19 에 백엔드가 0.17.0→0.19.0 을 하루에
  올렸고, 같은 필드의 의미가 이틀 새 세 번 바뀐 적도 있다(`restartRequired`). 그래서 화면은
  응답을 읽고, **시점·상태를 예측해 문구에 박지 않는다** — 박으면 다음 변경에 조용한
  거짓말이 된다.
- **공개 이력은 되돌릴 수 없다.** 커밋 전에 유출 감사를 끝낸다. 사설 IP·실기 호스트명·계정명·
  토큰은 주석·placeholder·테스트 픽스처·문서 전부에서 뺀다.
